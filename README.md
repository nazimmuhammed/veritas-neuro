# Veritas Neuro

Verified medical-record intelligence for people living with neurological conditions.

A hierarchical multi-agent system (LangGraph) that builds a patient timeline from
scattered reports, verifies every claim against source documents, flags
contradictions, and produces clinician-approved, provably untampered summaries.

## Run locally

    cp .env.example .env   # then edit passwords
    docker compose up -d
